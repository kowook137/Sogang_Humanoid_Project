# 녹음 방법

- 본인의 평소 부산 억양으로 어르신께 편하게 이야기하듯 읽으세요. 사투리를 과장하지 마세요.
- 조용한 방, 같은 마이크와 거리(약 15~20cm), 같은 입력 볼륨을 유지하세요.
- 학습용은 WAV PCM 16-bit 또는 24-bit, mono 44.1kHz 또는 48kHz 권장. MP3를 WAV로 바꾸는 것은 원음 녹음을 대체하지 않습니다.
- 50개를 문장당 파일 하나씩 recordings/raw/busan_001.wav ~ busan_050.wav로 저장하세요.
- 각 파일 앞뒤 약 0.2~0.5초 여유를 두고, 긴 침묵·음악·다른 사람 목소리·울림·클리핑을 피하세요.
- 실수하면 해당 문장을 새로 녹음하세요. 원본은 보존하고 선택한 테이크를 별도 정리하세요.
- 대본과 실제 발화가 정확히 일치해야 합니다. 숫자도 대본에 적힌 말대로 읽으세요.
- 단어가 어색하면 먼저 대본과 CSV를 함께 고친 뒤 녹음하세요.
- 기준음성은 3~10초 제약을 확인하여 준비합니다. 원본을 자르거나 덮어쓰지 않고 별도 전처리 사본을 만듭니다.
- 자동 음질 검사는 선별 보조입니다. 잡음·발음·전사 일치는 사람이 직접 들어서 최종 확인합니다.
- 아직 녹음하지 않은 행은 pending/false입니다. 실제 녹음과 청취 검수 뒤에만 상태를 변경합니다.
- 50개는 초기 few-shot 실험용입니다. 음색·부산 억양 품질은 실제 합성 청취로 판단하며 보장하지 않습니다.
