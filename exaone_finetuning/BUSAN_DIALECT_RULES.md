# 현대 부산 존댓말 정본 규칙 v1

상태: AI-Hub 부산 화자 원말뭉치 확인 및 1차 부산 화자 피드백 반영
작성일: 2026-09-08

프로젝트 결정: 2020년 AI-Hub 부산 발화는 현재 목표, 특히 어르신 상대 대화의 표현
근거로 사용한다. 단, 화자 메타데이터와 실제 용례가 확인된 문장 기능 안에서만 쓴다.

## 1. 적용 범위

- 화자: 부산의 젊은 성인형 대화 로봇
- 청자: 주로 어르신
- 목표: 알아듣기 쉬운 현대 부산 존댓말
- 비목표: 넓은 경상도 혼합어, 대구·경북 말투, 방송식 사투리, 옛날 말투 재현
- 텍스트에서 지역색을 과장하지 않는다. 부산말의 중요한 부분인 억양은 TTS에서 별도로
  검증한다.

## 2. 근거 수준

### 문헌으로 확인된 사항

- 동남 방언 종결어미는 평서·의문·명령·청유와 상대높임 등 문장 기능에 따라 구별된다.
- 의문사가 없는 질문의 `-나` 계열과 의문사가 있는 질문의 `-노` 계열은 기능이 다르다.
- 명령형에는 `-으소/-이소` 계열이 있다.
- `-니더/-심더` 계열은 동남 방언의 설명형·높임형에 존재한다.
- 문말 `-대이/-데이` 계열이 존재하지만 모든 평서문의 범용 존댓말 대체형은 아니다.
- 경북과 경남 내부에도 형태 차이가 있으므로 동남 방언 자료를 곧바로 부산어로 간주하지
  않는다.

참고: 이상환, 「동남방언」, 국립국어원 《새국어생활》 8권 4호, 1998, 116-137쪽.

### AI-Hub 원말뭉치에서 확인된 사항

- 출생지·주 거주지·현재 거주지가 모두 부산인 5,160명의 발화 687,179개가 있다.
- 그중 표준어형과 방언형이 다른 발화는 112,398개이며 방언 표시 어절은 144,022개다.
- 단순 부분문자열이 아니라 문장 끝을 기준으로 집계하면 `-예` 802건, `-아이가`
  3,075건, `-노` 654건, `-데이/-대이` 51건, `-습니더/-심더` 4건이었다.
- 이는 전체 발화 빈도이며 높임·문장 기능·대화 상대를 통제한 비율은 아니다. 특히
  `-노/-나`가 많다는 이유만으로 어르신 상대 AI 답변에 사용할 수는 없다.

### 아직 확인되지 않은 사항

- 현대 부산의 연령·높임·상대 관계별 어미 빈도
- 어르신 상대 로봇 대화에서 선호되는 사투리 강도
- `-데이`, `-니더`, `-예`, `-이소`의 목표 비율

위 빈도는 부산 지역·연령 태그 원말뭉치를 확보하기 전까지 언어학적 사실로 단정하지
않는다. 아래 비율은 첫 30개 검수용 임시 설계값이다.

## 3. 기능별 생성 규칙

| 기능 | 기본 전략 | 제한적으로 허용 | 피할 것 |
|---|---|---|---|
| 정보 설명 | 표준어 존댓말 중심 | 문단당 부산 표지 0~1회 | 모든 문장을 `-니더`로 종결 |
| 공감·확인 | 자연스러운 공감 후 답변 | `-네예`, `-지예` | 문장마다 `예` 덧붙이기 |
| 권유·요청 | 구체적인 행동을 부드럽게 요청 | `-보이소`, `-하이소`, `-마이소` | 명령을 과도하게 강하게 만들기 |
| 주의·강조 | 안전상 중요한 사실을 분명히 전달 | 문맥에 맞는 `-데이` 1회 | 평범한 절차 설명마다 `-데이` 사용 |
| 질문 | 청자 높임과 관계를 우선 | 검수된 존대 지역 의문형만 사용 | 어르신에게 `-노/-나` 사용 |
| 기억·일정 확인 | 이름·시간·장소를 그대로 반복 | `-네예`, 드문 `-니더` | 이름·숫자·수정사항 변경 |
| 센서 불확실성 | 모른다고 밝히고 확인법 제시 | 지역 표지 0~1회 | 현재값 추측 |
| 응급·의료 | 표준화된 안전문구 우선 | 행동 지시 한 곳만 부산형 | 사투리 때문에 의미·우선순위 변경 |

## 4. 첫 검수용 임시 분포

이는 실제 부산어 빈도 주장이 아니라 모델의 어미 붕괴를 막기 위한 상한이다.

- 한 답변의 눈에 띄는 부산 표지: 보통 0~2개, 최대 3개
- `-니더` 계열: 현재 목표 화자의 1차 검수에 따라 기본 금지. 다른 부산 화자와 실제
  현대 발화 자료에서 자연스러움이 확인될 때만 다시 검토
- `-데이` 계열: 주의·강조·확인 기능에서만 한 답변 최대 1회
- `-이소` 계열: 실제 권유·요청·금지 문장이 있을 때만 사용
- `-예/-지예/-네예` 계열: 공감·확인에서 사용하되 기계적으로 덧붙이지 않음
- `-주이소/-보이소/-마이소/-하이소` 계열: AI-Hub 부산 화자에게 실제 용례가 있으므로
  원문이 요청·권유·금지·행동 지시일 때만 같은 기능으로 변환
- `-노/-나` 계열: 부산 사용자 입력의 이해 대상으로는 포함하지만 어르신 상대 AI의
  존댓말 출력에는 사용하지 않는다.
- 표면적 방언 표지가 없는 자연스러운 표준어 존댓말도 정답으로 허용한다.

## 5. 1차 부산 화자 피드백으로 확정한 보존 규칙

- 표준 문장을 그대로 허용한다는 이유로 내용을 다른 말로 바꾸지 않는다.
- `무엇→뭐`, `가장→제일`, `-습니까→-으세요`는 부산 방언 변환이 아니므로 하지 않는다.
- `맞나요?→맞지예?`처럼 질문자의 확신 정도나 답변 요구 방식을 바꾸지 않는다.
- 평체로 느껴지는 `-ㄴ데이` 절과 존댓말 문장을 억지로 이어 붙이지 않는다.
- 표준 표기 문장은 이후 부산 억양 TTS로 지역성을 구현할 수 있다.
- 현재 목표 화자 기준에서 `-니더`는 자연스럽지 않으므로 기본 생성 목록에서 제외한다.
- 데이터 단계에서는 보수적으로 확실한 표현만 사용하고, 억양·리듬·음색은 부산 화자의
  실제 음성 또는 동의받은 프로젝트 화자 음성으로 TTS 단계에서 학습·검증한다.

## 6. 자동검사가 할 일과 못 할 일

자동검사는 숫자, 영문, 부정, 질문 기능, 응급 핵심어, 금지 표현, 어미 반복을 검사한다.
자동검사는 부산 사람이 실제로 자연스럽게 느끼는지 확정할 수 없다. `usable`은 승인
후보라는 뜻이 아니라 사람이 읽어볼 수 있다는 뜻이다.

## 7. 승인 절차

1. 부산 화자가 기준문장 30개를 `승인/수정/거절`한다.
2. 수정 이유를 기능, 높임, 지역성, 과장, 비문 중 하나로 기록한다.
3. 승인·수정된 문장만 Gemini의 예시로 사용한다.
4. 비공개 20문장 시험에서 의미 보존과 부산 화자 자연스러움을 확인한다.
5. 기준 통과 전에는 100개 추가 생성을 하지 않는다.
6. 최종 학습 데이터는 가능하면 부산 화자 2명이 검수한다.
