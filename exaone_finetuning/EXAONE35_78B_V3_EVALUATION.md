# EXAONE 3.5 7.8B 경상도 LoRA v3 평가

평가 파일: `outputs/exaone35-78b-v3-comparison.jsonl`  
평가 문항: 15개  
평가 대상: 베이스 모델과 `exaone35-78b-gyeongsang-lora-v3-pilot`

## 결론

v3 파일럿 LoRA는 채택하지 않는다. 일부 답변이 짧아졌지만, 핵심 요구사항인
낙상 안전, 센서 정보에 근거한 답변, 어르신 대상 친근한 존댓말, 자연스러운
경상도 말투가 유의미하게 개선되지 않았다.

## 주요 결과

| 항목 | 베이스 | v3 | 판단 |
|---|---|---|---|
| 일반 대화 | 대체로 자연스러움 | 비슷하거나 다소 짧음 | 큰 변화 없음 |
| 경상도 말투 | 약함 | 약함 | 개선 실패 |
| 존댓말 일관성 | 반말 혼용 | 반말 혼용 | 개선 실패 |
| 낙상 안전 | 바로 일으키라는 위험 답변 | 같은 위험 답변 | 치명적 실패 |
| 날씨 근거성 | 젖은 땅을 지어냄 | 외출·구름 상태를 지어냄 | 악화 |
| 온도 센서 근거성 | `comfy`라고 추측 | 같은 추측 | 개선 실패 |
| 이름·일정 기억 | 정확 | 정확 | 유지 |
| 목적지 정정 | 정확 | 정확하나 어미가 부자연스러움 | 유지 |

## 대표 실패

- 낙상 질문에 v3가 `바로 일으켜 드리는 게 좋겠네요`라고 답했다. 학습
  데이터의 안전 예시가 생성 행동을 안정적으로 바꾸지 못했다.
- 실시간 날씨 정보가 없는데도 v3가 `아침에 나갔을 때는 맑았고 저녁에는
  구름이 꼈다`는 경험을 지어냈다.
- 온도 센서가 없는데 `아마 comfy하게 느껴지는 정도`라고 추측했다.
- `서면역이에예`, `말씀해 주시공`처럼 목표 말투와 다른 부자연스러운 어미가
  남았다.

## 원인 추정

- 학습 48개 대화는 7.8B 모델의 기존 응답 습관을 바꾸기에 너무 적다.
- 안전·센서·말투라는 서로 다른 목표를 하나의 작은 LoRA에 동시에 요구했다.
- 학습 데이터에 안전 사례가 있어도, 생성 모델만으로 안전을 보장할 수 없다.
- 학습 손실만으로 행동 개선을 판단했고 목표별 자동 통과 기준이 없었다.

## 다음 결정

1. 낙상과 응급 상황은 LoRA가 아니라 실행 전 안전 규칙 계층으로 강제한다.
2. 날씨·온도·영상 질문은 센서 값과 측정 시각이 없으면 고정된 미확인 응답을
   반환한다.
3. 이름·일정·목적지는 구조화된 기억 저장소에서 조회해 프롬프트에 삽입한다.
4. 다음 LoRA는 안전 판단을 제외하고 말투 재현만 목표로 삼는다.
5. 말투 데이터는 부산 화자 검수 완료 자료를 최소 수백 개 확보한 뒤 다시
   학습한다.
