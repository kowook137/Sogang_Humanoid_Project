# EXAONE 경상도 대화 모델 정본 명세

상태: 승인된 작업 기준  
최종 갱신: 2026-09-01 (KST)

이 문서는 대화 기억보다 우선하는 프로젝트 정본이다. 데이터 생성, 검수, 학습, 평가
과정에서 판단이 충돌하면 이 문서를 따른다. 기준 변경은 이유와 실험 결과를 함께 Git에
기록한다.

## 1. 목표와 범위

- 최종 텍스트 대화 모델은 `LGAI-EXAONE/EXAONE-3.5-7.8B-Instruct`를 사용한다.
- 모델은 표준어·경상도 말투·가벼운 구어 입력을 이해하고 현대 부산·경남의 친근한
  존댓말로 답한다.
- 주요 대화 상대는 어르신이지만 답변 내용과 어휘는 부자연스럽게 유아화하지 않는다.
- 일반 일상, 감정, 관계, 생활 조언, 기술 도움, 주제 전환, 정정, 되묻기와 3~6턴
  문맥 유지를 포함한다.
- 음성 대화는 텍스트 모델 검증 후 ASR과 TTS를 별도 계층으로 연결한다. 텍스트 LoRA가
  음성 인식이나 억양을 학습했다고 간주하지 않는다.

## 2. 모델별 역할

- EXAONE 3.5 7.8B: 최종 대화와 기본 지식·추론
- Gemini 교사 모델: 표준 답변 및 경상도 후보 생성만 담당
- QLoRA: EXAONE의 기존 대화 능력을 보존하면서 말투와 대화 행동을 보강
- 구조화된 기억: 이름, 일정, 사용자가 명시적으로 기억해 달라고 한 정보
- 센서 계층: 온도, 낙상, 위치 등 현재 측정값과 측정 시각
- 안전 규칙: 낙상·응급·의료 상황의 필수 행동과 금지 행동

기억, 센서값, 실시간 날씨와 안전 판단을 LoRA 암기에 맡기지 않는다.

## 3. 말투 기준

- 현대 부산·경남 말투
- 친근한 존댓말
- 강도 약~중
- 표준어 질문에도 동일한 말투 유지
- 한 문단의 눈에 띄는 방언 어미는 보통 두세 번 이내
- 내용 정확성과 안전성이 사투리 강도보다 우선

다음과 같은 방송식·옛날식·기계적 표현은 피한다.

- `아이가`, `데이` 반복
- `안녕하십니꺼`, `참말로`, `쪼매쪼매`
- `말입니더`, `라카믄`, `할라카믄`, `끼라예`, `가꼬`
- `우예예`, `어떠세요예`, `깁니더`, `심니더`와 같은 비문
- 모든 문장을 `-습니더`, `-보이소`로 끝내는 패턴

## 4. 데이터 생성 원칙

1. 교사 모델이 질문에 대한 정확하고 완전한 표준어 답변을 먼저 생성한다.
2. 별도 호출에서 표준 답변의 말투만 경상도 존댓말 후보로 변환한다.
3. 사실, 숫자, 고유명사, 안전 정보, 조언의 강도와 문장 기능을 보존한다.
4. 후보별 자동검사를 수행한다. 한 후보의 실패로 다른 후보를 버리지 않는다.
5. 자동 usable은 최종 승인이 아니다. 부산·경남 화자가 `accept`, `edit`, `reject`를
   결정한다.
6. 최종 학습에는 사람이 승인하거나 직접 수정한 데이터만 넣는다.
7. AI-Hub 자료는 라이선스와 개인정보 조건을 확인한 뒤 실제 표현의 근거로 사용한다.

## 5. 데이터 규모

- 1차 Pro 파일럿: 10개, 완료 후 사람 검수
- 확장 파일럿: 100개, `dataset_plan.json`의 `pilot_100` 비율 준수
- 최종 승인 학습 데이터: 1,000레코드 이상
- 목표 assistant 발화: 2,000~3,000턴
- 학습에서 완전히 분리한 평가 데이터: 200레코드 이상

1,000개를 임의의 단일 질문·답변으로 채우지 않는다. 다중 턴, 정정, 주제 전환,
안전, 기억, 센서 불확실성을 반드시 포함한다.

## 6. 검수 인력과 판정

- 부산·경남 화자 최소 2명이 자연스러움을 독립 평가한다.
- 의견이 다르면 제3 검수자가 판정한다.
- 질문에 실질적으로 답하지 않거나 의미가 바뀐 문장은 말투가 좋아도 reject한다.
- 최종 데이터에는 검수 여부와 선택·수정 기록을 남긴다.

## 7. 학습 원칙

- 베이스 모델과 토크나이저 버전을 고정하고 기록한다.
- QLoRA 학습률과 epoch를 보수적으로 설정하고 검증 손실만으로 성공을 판단하지 않는다.
- 체크포인트마다 베이스 모델과 동일한 비공개 평가 세트를 비교한다.
- 기존 내용 정확도가 유의미하게 하락하면 말투 점수가 높아도 채택하지 않는다.
- 테스트 데이터 또는 그 변형을 학습 데이터에 합치지 않는다.

## 8. 완료 정의

`evaluation_plan.json`의 모든 필수 기준을 통과해야 텍스트 MVP 완료로 판정한다.
음성 MVP는 그 후 ASR·TTS 및 실제 마이크 환경 평가를 별도로 통과해야 한다.
